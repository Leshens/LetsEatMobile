# Let's Eat — Mobile Application

Mobile application developed as part of the Let's Eat restaurant application.

## Features

- User authentication
- Email and password authentication
- Google Sign-In
- Firebase Authentication
- Communication with the Let's Eat REST API

## Technologies

- Kotlin
- Android
- Firebase Authentication
- Google Sign-In
- REST API

## Project

The application was developed as the mobile component of the Let's Eat restaurant platform.

It communicates with the backend REST API and provides users with mobile access to the application.

## Authentication

The application uses Firebase Authentication and supports:

- Email and password login
- Google Sign-In
